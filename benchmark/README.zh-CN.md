# Benchmark 记录与上游数据条款

本目录中的 JSONL 文件是派生的评测记录。根据维度不同，一条记录可能包含
数据集或序列标识、提示词、统计摘要、目标值、异常元数据、分类标签或其他
期望答案字段。它们不是 `data/` 下的原始文件，但派生值仍可能受到上游数据
集条款约束。

将本目录发布到公开仓库前，必须逐项核对这里所代表的每个上游来源的条款。
尤其要注意 Yahoo S5 以及其他需要注册或仅限研究用途的来源，它们可能限制
再分发。若某个来源不允许再分发派生值，应先移除受影响的记录，再重新生成
`evaluation_manifest.json` 及所有依赖它的摘要或 digest；本地校验通过不等于
获得了再分发许可。

本源码包保留这些记录，是因为公开校验和 benchmark 契约依赖它们。
精确论文分数并未包含在内；完整运行所需的外部输入见
`../docs/REPRODUCIBILITY_STATUS.md`。
